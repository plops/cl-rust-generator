
wir arbeiten auf einen STM32G474CEU6

programmiert kann dieser werden mittels STLink-STM32 programmierer. ich habe dies mit den beispielprogrammen in embassy verifiziert:

```
embassy/examples/stm32g474 $ cat .cargo/config.toml
[target.'cfg(all(target_arch = "arm", target_os = "none"))']
runner = "probe-rs run --chip STM32G474RETx"

[build]
target = "thumbv7em-none-eabi"

[env]
DEFMT_LOG = "trace"
```
