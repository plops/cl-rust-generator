# Tutorials für den `optics`-Ray-Tracer

Nummerierte, aufeinander aufbauende Tutorials, die den differenzierbaren
optischen Ray-Tracer aus `../source6` in realistischen Arbeits­abläufen zeigen.

| Nr. | Verzeichnis | Thema |
|-----|-------------|-------|
| 01  | [`01_doe_cooke_triplet`](01_doe_cooke_triplet/) | Statistische Versuchsplanung (DoE): Den Solver aus Python steuern, ein unscharfes Cooke-Triplet über eine Rastersuche neu fokussieren und das Ergebnis mit dem eingebauten Gradienten­abstieg absichern. |

Jedes Tutorial enthält einen ausführlichen Bericht (`Bericht.md`) und lauffähigen Code.

## Voraussetzungen

```sh
cd ../source6 && cargo build --release
```
